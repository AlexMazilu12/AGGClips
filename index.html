Personal creator tool

Live-stream highlights, turned into vertical clips.

Agg Clips Studio is the desktop tool behind the @aggclips accounts. It watches public live streams, spots the moments where chat and audio explode, cuts them into captioned 9:16 clips, and, only after the owner reviews and approves each one, publishes them to the owner's own YouTube, Instagram and TikTok accounts.

  1. DetectPublic stream data (chat activity, laughter, audio peaks) marks the best moments.
  2. ClipEach moment becomes a vertical clip with burned-in captions and a title.
  3. ReviewThe owner watches every clip and approves or rejects it by hand.
  4. PublishApproved clips go to the owner's own channels through official APIs.

How the TikTok integration works

  • The owner signs in once with Login Kit and grants two permissions: user.info.basic (to show which account is connected) and video.upload (to send a clip to the account's drafts).
  • When the owner approves a clip, the tool uploads it with the Content Posting API (Upload). The video lands in the TikTok inbox as a draft; the owner opens TikTok, edits the post and publishes it from the app.
  • Nothing is posted publicly by the tool, nothing is posted without a manual review, and only the owner's own account is connected. There are no other users.

Other platforms

  • YouTube: uploads approved clips as Shorts to the owner's channel with the YouTube Data API (youtube.upload). This tool uses YouTube API Services.
  • Instagram: publishes approved clips as Reels to the owner's professional account with the Instagram Graph API.
  • Twitch, Kick, YouTube: reads public live-stream information (who is live, titles, viewer counts, public chat) to find highlights.
